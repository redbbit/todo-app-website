🤖 Android 怎么装

  1. 点上面「Android 下载」，把 TodoApp_Android_1.5.4.apk 保存到手机。
  2. 打开下载好的 APK。第一次安装会提示「未知来源应用」，选允许即可。
  3. 不同品牌入口略有差别： 小米：设置 → 隐私保护 → 特殊权限设置 → 安装未知应用； 华为/荣耀：设置 → 安全 → 更多安全设置 → 安装未知应用； OPPO/vivo/三星：设置 → 应用管理 → 右上角菜单 → 特殊访问权限 → 安装未知应用。
  4. 装完打开，首次启动会问是否允许通知，建议允许，才有到期提醒和每日摘要。
  5. 提示「有更新」时，可在 设置 → 关于 里直接下载新版覆盖安装，数据不会丢。

🪟 Windows 怎么装

  1. 点上面「Windows 下载」，得到 TodoApp_1.5.4_win64.zip。
  2. 右键压缩包 → 全部解压缩（建议解压到 D:\TodoApp 这类纯英文路径）。
  3. 进解压出来的文件夹，双击 TodoApp.exe 就能用，不用安装、不写注册表。
  4. 若 Windows 弹出蓝色「已保护你的电脑」：点更多信息 → 仍要运行（个人签名软件首次运行都会这样）。
  5. 想放到任务栏/桌面：右键 TodoApp.exe → 发送到 → 桌面快捷方式。
  6. 卸载直接删整个文件夹，数据存在你自己的数据目录里，不会被一起删掉。
下载慢 / 下不动怎么办？

安装包托管在 GitHub Releases。若直连慢，可复制下载链接到任意下载工具（如迅雷、Motrix、wget）里跑；或用手机热点换个网络再试。

提示「文件可能有害」是正常的吗？

正常。这是独立开发者未做付费代码签名的通用提示，不是病毒。Windows 端请点「更多信息 → 仍要运行」；若仍不放心，可用杀毒软件扫描后再运行。

旧版本能直接覆盖升级吗？

可以。Android 直接装新 APK；Windows 解压到新文件夹即可，两边数据都各自保留。建议升级前先在 设置 里做一次备份/同步。

手机和电脑能同步吗？

可以，在同一局域网下通过 设置 → 同步 配对即可；两端都支持手动/自动同步同一份任务数据。
